# PEAK Inspection

QR·바코드 기반 공정 불량 등록, 재검사, 처리 완료 및 전후 사진 관리 웹 앱입니다.

1. 게시된 HTTPS 주소를 Chrome 또는 Safari에서 엽니다.
2. **품번 관리 → Excel 업로드**에서 SAP PN·Description 목록을 가져옵니다.
3. **Drive 연결**로 로그인하면 사진을 본인 Google Drive에 저장할 수 있습니다.
4. 가운데 QR, 하단 바코드 순서로 스캔하고 공정·불량 내용을 등록합니다.

품번 목록과 검사 이력은 각 기기의 브라우저에 저장됩니다. 기존 로컬 앱의 이력은 백업 파일로 복원하고, 품번은 Excel로 가져오세요. 사진만 Google Drive에 저장되며 이력은 기기 간 자동 공유되지 않습니다.

실제 품번 자료·검사 이력·사진은 이 저장소에 포함되어 있지 않습니다. 공개 OAuth 클라이언트 ID만 포함하며 Google 로그인에는 게시 주소의 OAuth 허용 설정이 필요합니다. 테스트 모드에서는 등록된 테스트 계정만 연결할 수 있습니다.

ZXing 및 SheetJS의 라이선스는 index.html에 포함되어 있습니다.
