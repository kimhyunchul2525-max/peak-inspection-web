# PEAK Inspection

PDA 스캔·카드 사진 문자 인식으로 공정 불량을 등록하고 생산팀 작업·품질 재검사·전후 사진을 관리합니다. 한국어·영어·대만 중국어·베트남어·인도네시아어를 지원합니다.

[공정검사 앱 열기](https://kimhyunchul2525-max.github.io/peak-inspection-web/)

1. 게시된 HTTPS 주소를 i630 PDA 또는 아이폰 Safari에서 엽니다.
2. 공개 승인된 기본 품번 905개(SAP PN·Description·Mold)가 자동 준비됩니다. 품번 관리에서 **Google 로그인** 후 추가·수정하거나 Excel로 업데이트하면 모든 접속 기기에 실시간으로 반영됩니다. 조회에는 로그인이 필요하지 않습니다.
3. 가운데 **QR 카메라 스캔**으로 Card No를 읽고, **품번 바코드 카메라 스캔**으로 상단 오른쪽의 짧은 바코드를 읽으면 SAP PN과 Description이 표시됩니다. 카메라 창에서 **코드 사진으로 읽기**도 가능합니다. PDA 스캐너는 키보드 입력 모드로 QR → 품번 바코드 순서로 스캔하고 Enter/Tab 또는 인식 버튼으로 반영합니다. 기존 긴 하단 바코드는 PDA 입력으로도 사용할 수 있습니다.
4. 아이폰·PDA에서 **카드 전체 촬영 · 글자 인식** 또는 **카드 사진 선택**을 누르면 발행일자·금형번호·원료명(Material)·오더 번호를 추가합니다. SAP PN·로트 카드 번호도 확인하며, 인식하지 못한 값은 직접 입력합니다. 실제 카드와 모든 값을 대조해 확인 후 적용하세요. 인식용 사진과 카메라 영상은 기기에서만 처리하며 업로드하거나 제품 증명 사진으로 보관하지 않습니다. 첫 문자 인식 시 실행 파일을 내려받으므로 인터넷 연결이 필요합니다.
5. FOL·EOL·OQC 공정, 검사자, 불량 내용과 사진을 입력하여 **불량 등록**합니다. 등록한 건은 **등록 이력**의 생산팀 처리 대기 목록으로 이동합니다. 불량 등록일은 카드 발행일이 아닌 스캔·사진 선택일입니다.
6. 생산팀은 **등록 이력**의 각 행 오른쪽에서 **재검사 / Sorting / Scrap / 기타(직접 입력)** 검사 방법을 선택합니다. 작업자, 완료일, 전량 처리 결과와 사진을 입력하고 **재검사 진행 완료**를 누르면 **품질 재검사** 탭으로 이동합니다. 품질팀이 내용과 전후 사진을 확인해 **Pass**하면 처리 완료로 이동하며, **NG**이면 같은 불량 번호로 등록 이력에 반환되어 다시 검사 방법을 선택하고 진행합니다. 원래 등록일·불량 내용·사진과 회차별 생산/품질 판정을 보존합니다. Scrap도 품질 판정을 거칩니다. 기존 완료 이력은 그대로 유지하며, 각 탭의 목록과 회차별 처리 이력을 Excel로 내려받을 수 있습니다.
7. 팀 공통 저장 모드가 활성화된 배포에서는 Google 로그인 후 관리자 승인을 받아 같은 기록과 사진을 확인합니다. 품질팀은 등록·판정, 생산팀은 작업 결과 입력을 담당합니다. 공통 사진 저장소가 구성되면 별도 Drive 연결 없이 사진이 업로드됩니다. 기존 기기 기록은 관리자가 명시적으로 가져오기 전까지 자동 공유되지 않습니다. 사진 저장소 설정 대기 중에는 새 사진 업로드가 차단됩니다. 로컬 저장 모드는 기존 Drive 사진 저장을 사용하며 처음 사진을 추가할 때 권한을 연결합니다.

QR→LTC Excel 조회와 긴 하단 바코드의 카메라 인식·분할 촬영 기능은 포함하지 않습니다. 저장된 불량 기록과 이전 LTC 조회 출처 기록은 유지합니다.

검사 이력과 사진은 공개 저장소에 포함되지 않습니다. 품번 목록은 Google Firebase 공통 저장소로 공유합니다. 로그인 시 기존 브라우저에서 추가·수정한 품번도 공통 목록과 충돌하지 않는 항목부터 옮깁니다. 기존 브라우저 목록은 복구용으로 보존합니다. 인터넷 연결이 끊기면 마지막으로 받은 목록으로 조회할 수 있으며 품번 변경은 연결 복구 후 가능합니다. Excel은 변경 항목 400개 이내로 나누어 업로드하세요. 이 빌드의 팀 공통 이력: **설정 대기**, 공통 사진: **설정 대기**. 설정 대기인 로컬 모드에서는 검사 이력은 각 기기의 브라우저에 저장되며 기기 간 자동 공유되지 않습니다. 전체 백업을 보관하세요.

브라우저 앱에 필요한 공개 OAuth 클라이언트 ID가 포함됩니다. 로그인 토큰이나 클라이언트 비밀번호는 포함하지 않습니다. 기존 사진용 Google Drive 연결은 drive.file 권한만 사용합니다. 공통 품번·팀 이력·공통 사진은 같은 Firebase Authentication Google 로그인을 사용합니다. 팀 기록과 사진은 승인된 담당자에게만 공개되며 변경 이력은 서버에 보존합니다. Firebase 브라우저 설정은 공개 식별자이며 관리자 비밀번호나 서비스 계정 키가 아닙니다. 자체 배포 시 OAuth 허용 주소, Firebase 프로젝트와 보안 규칙을 별도로 설정해야 합니다.
