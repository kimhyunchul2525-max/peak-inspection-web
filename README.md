# PEAK Inspection

QR·바코드 기반 공정 불량 등록, 재검사, 처리 완료 및 전후 사진 관리 웹 앱입니다. 한국어·영어·대만 중국어·베트남어·인도네시아어를 지원합니다.

[공정검사 앱 열기](https://kimhyunchul2525-max.github.io/peak-inspection-web/)

1. 게시된 HTTPS 주소를 Chrome 또는 Safari에서 엽니다.
2. 공개 승인된 기본 품번 905개(SAP PN·Description·Mold)가 자동 준비됩니다. 처음 사용할 때 Excel 업로드는 필요하지 않습니다.
3. **Drive 연결**로 본인의 Google 계정에 로그인하면 사진을 본인 Google Drive의 비공개 폴더에 저장할 수 있습니다.
4. **LTC 발행이력**에서 카드 번호와 SAP PN이 있는 Excel을 업로드하면 QR만으로 즉시 조회할 수 있습니다. 새 발행분은 최신 Excel을 각 검사 기기에 업로드해야 반영됩니다. 목록에 없는 카드는 가운데 QR, 하단 바코드 순서로 스캔하고 FOL·EOL·OQC 공정과 불량 내용을 등록합니다. 재검사 후 최종 판정을 저장하면 처리 완료에서 관리합니다.

아이폰에서 긴 하단 바코드가 잘 읽히지 않으면 QR 인식 후 **하단 바코드 촬영 · 권장**을 누르세요. 아이폰을 가로로 들고 바코드와 양 끝의 흰 여백을 크게 촬영합니다. 촬영한 사진은 기기 안에서 기울기를 보정해 분석하며 서버로 보내지 않습니다. 실시간 카메라 화면에서는 지원되는 카메라·확대·조명 설정을 선택할 수 있습니다.

품번 목록과 검사 이력은 각 기기의 브라우저에 저장됩니다. 기본 품번 자료는 공개되어 누구나 이용할 수 있으며, **품번 관리**에서 직접 추가·수정하거나 Excel로 업데이트·다운로드할 수 있습니다. 이전 공개 버전에서 만들어진 빈 품번 목록은 기본 목록으로 준비되고, 이미 수정하거나 가져온 품번 목록은 유지됩니다.

검사 이력과 사진은 공개 저장소에 포함되지 않습니다. 사진만 본인의 Google Drive에 저장되며 검사 이력과 사용자별 품번 변경은 다른 사용자·기기에 자동 공유되지 않습니다. 기존 이력은 백업 파일로 복원하고, 사용자별 품번은 Excel로 가져오세요.

브라우저 앱에 필요한 공개 OAuth 클라이언트 ID가 포함됩니다. 로그인 토큰과 클라이언트 비밀번호는 포함하지 않습니다. Google 연결은 이 앱이 만든 파일 또는 사용자가 이 앱으로 선택한 파일에 대한 drive.file 권한을 사용합니다. 자체 배포 시 해당 주소를 허용하는 OAuth 클라이언트를 설정해야 합니다.
